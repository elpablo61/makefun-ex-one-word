One-word verdict on an ex, entered in the [Describe Your Ex in One Word](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7) bounty on make.fun.

## The word

**beta** — a test version: buggy, unfinished, shipped early so the next person gets the stable release.

## How it works

`main.ts` (Node 22) writes exactly one word — `beta`, no trailing newline, no extra text — to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).

Run it locally:

```sh
node main.ts
```
